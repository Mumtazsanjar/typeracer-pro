## ✨ Features

- ⏱️ **Three time modes** — 30s, 60s, and 120s
- 📊 **Live statistics** — WPM, accuracy, timer, and streak
- 🎯 **Three difficulty levels** — Easy, Medium, and Hard
- 🎨 **Dark & Light themes** with smooth UI transitions
- ✅ **Real-time typing feedback** — correct and incorrect characters highlighted
- 🔥 **Streak counter** — tracks consecutive correct words
- 📈 **Performance rating** — Beginner to Expert based on WPM
- 💾 **Local history** — last 10 test results stored locally
- 📱 **Responsive design** — optimized for desktop, tablet, and mobile
- ⌨️ **Keyboard shortcuts** — Tab to restart and Escape to close modals
- 📝 **90+ typing passages** across different difficulty levels
- 🔒 **Privacy-focused** — typing results are stored locally and are not sent to a server

🔐 Privacy

TypeRacer Pro does not require user registration or an account.

Typing test results and preferences such as theme settings are stored locally in the browser using localStorage.

No typing data is intentionally sent to or stored on a backend server.

📱 Responsive

TypeRacer Pro is designed to work across:

Desktop
Laptop
Tablet
Mobile phones

The typing interface, navigation, content pages, tables, and blog articles are optimized for different screen sizes.
